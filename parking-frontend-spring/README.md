
# Parking Frontend (React + Vite) para Spring Boot

Variables:
- `VITE_API_BASE` (opcional) por defecto `http://localhost:8080/api`

Comandos:
```bash
npm install
npm run dev
```

Flujo:
1) Login (admin / admin123) -> guarda token en localStorage.
2) Dashboard -> ocupa endpoints de ocupación, ingresar/sacar.
3) Historial -> lista, filtra, elimina.
